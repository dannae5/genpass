# 🔐 genPass - Generador de Contraseñas Seguras

`genPass` es una herramienta interactiva en Python para generar contraseñas seguras y personalizadas. Puedes crear claves aleatorias, especificar parámetros como longitud, números, caracteres especiales, y mucho más. Además, puedes aplicar hash, guardar en archivos o copiar al portapapeles.

---

## 🚀 Características

- Generación de contraseñas personalizadas (con palabra base, números, caracteres especiales).
- Generación de contraseñas totalmente aleatorias.
- Capacidad para generar múltiples contraseñas a la vez.
- Aplicación de hash (SHA256, MD5, SHA1, etc.) a las contraseñas.
- Guardado en archivos de texto.
- Copia al portapapeles.
- Interfaz por consola con limpieza de pantalla automática.

---

## ⚙️ Requisitos

- Python 3.7 o superior
- Paquetes listados en `requirements.txt`
